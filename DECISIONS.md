|E-001|**Leitwert is the core primitive** — a compressed world-reference; modifiers are additive.|The compound alone triggers coherent design output; everything else individualizes.|
|E-014|North star = **speed to a credible, surprising direction.**                      |Tempo is the lead metric; human verdict is the quality ground truth (was E-018).    |
|E-024|**The vibe is the deliverable.** Leitwert (directive) and **Creative Derivation (why)** are separate fields, never blurred.|Prevents the *Eisblumen* failure — decorative prose leaking in as if it were a spec.|
|E-026|Input = **natural-language briefing**; the model orchestrates brief → vibe. Blank slate must work.|No keyword lexicon as the generative source; the user briefs, the model interprets. |
|E-029|LLM layer = **Vercel AI Gateway** via a thin `api/` proxy; one key, server-side only.|Zero markup, `caching:'auto'`, model fallbacks. Key never client-side (OIDC on Vercel).|
|E-030|**Model tiers**: Studio = strong (Sonnet); judge/inner-loop = cheap (Haiku); **Opus = eval judge only**.|Bounds cost. Opus is the strict grader, not a generation path.                       |
|E-046|**No invented axes in generation.** Coherence comes from one distilled essence, not a shared coordinate. Axes may live only in measurement/steering.|Coordinates flatten analogy and breed cliché (the lesson of E-047).                  |
|E-047|**Radical rebuild → constellation UI + Structural Entanglement.** The axis/collision engine made surprising-but-useless results (surprise coupled to *missing* the brief). Replaced with a hex **constellation** (center Leitidee · per-engine clusters · ≤5 gold **anchors** as gravity) and **Engine D** (essence → burn clichés → far-but-rhyming worlds → affordance ≥5 → bridge → name). Deleted the axis/collision/Lab machinery.|The user's own end-to-end test exposed the eval metric had diverged from the northstar. Surprise and aptness must be *decoupled* (domain distance × structural resonance), then both maximized.|
|E-048|**Engine E — Latent Agent (Tier-0) + method harness.** Honest split: LLM leaps, **real embeddings measure "far"** (percentile rank, not absolute band). A method = 1 endpoint + 1 client fn + 1 `Source` entry, sharing the bridge contract + `bridgeToCard` + constellation. Tier-1 (corpus/pgvector, QD archive, cross-session novelty) deferred.|Embeddings measure/retrieve, never do analogy (they return topical neighbours). Keeps the growing method set modular and LLM-friendly.|
|E-049|**Engine F — Technique Workbench.** Fast pure-prompt Volume→Filter→Curation: wide field × operators, over-generate 3× / cut ⅔, cluster into orthogonal taste-directions. Reuses the harness.|The speed path — richer than a single pass, no embeddings/infra. The fast front; D supplies criteria, E supplies depth.|
|E-050|**Judge = on-target × surprise × craft** (was coherence/trigger/fit/freshness). Judge-select keeps the best per cluster; `--judge-tier` runs the eval on Opus.|The right question is "would a senior AD pitch this to THIS client, and is it non-obvious?" — not abstract coherence.|
|E-051|**Glossy-plastic theme**; docs compressed, engine specs committed to `docs/engines/`, legacy archive deleted.|User direction: away from retro paper; non-bloating, current docs only.|
|E-052|**Review hardening (all waves).** (1) Security: `api/_lib/guard.ts` caps the public, unauthenticated endpoints — clamp `n` to ≤8, cap free-text length, and block clients from forcing premium/Opus on generation (premium stays only on the cheap judge). (2) Fixed an id-collision regression (session-unique id prefix) introduced by persisting the working set. (3) Verification baseline: CI workflow (test+build+typecheck:api) + unit tests for the pure functions (guard, export, derive) — 2→11 tests. (4) Surfaced silent failures (`failedSources` banner; latent embed-fallback logged). (5) Deleted dead code (interpret endpoint+client, LEXICON, sharedSigns, mulberry32). UI re-grounded as an observatory instrument (frontend-design skill).|`/improve` audit: the open proxy was the one real cost/abuse risk; everything else was a thin test baseline + leftovers from the rebuild. Durable rate-limiting (Vercel KV/Upstash) deferred — input caps remove the amplification without new infra.|
|E-063|**Quality floor + north-star judge + novelty memory.** The judge's 4th axis encodes the stated north-star fail-conditions: **designValue** — is the output an *ableitbarer* design-value (world/material/style/mood) an image model can build an interesting world from, and NOT a story/narrative or a non-derivable abstraction (with craft re-pointed at "no generic AI bullshit")? Selection enforces a **score floor** (`select.ts`): cards under the bar never reach the board, and a cluster that comes back thin **regenerates once** rather than surfacing "best of bad". A persisted, capped **novelty memory** (`useVibeStore`) repels already-produced Leitwerte every round. No new infra. (Superseded a first cut that scored literal "renderability" — an over-fit to two casual user examples that also blurred Leitwert≠render, against E-024.)|Aligns selection with the real success metric — an efficient, usable, beautiful design-vibe to trigger an image model (no bullshit · no story · no empty abstraction) — and turns judge-select into a quality *guarantee* + non-repetition at scale, not just a per-round ranking. An unscored card (judge outage) is never floored out, so the floor degrades to "show-all", never an empty board.|
|E-064|**Refill removed — thin stays thin.** `produceForSource` no longer regenerates a cluster that comes back under the floor (reverses E-063's regenerate-once). A weak lane surfaces only its floor-passers — possibly few or none; the all-empty round still degrades to the `llmFallback` banner, never a hard-empty board.|An honest, occasionally-sparse board beats padding with a best-effort "best of bad" second pass, and it removes the worst-case doubled latency/cost of a weak round. The floor + novelty memory already carry the quality/non-repetition guarantee; the refill only bought back the cards the floor just rejected.|
|E-065|**Register-Vielfalt erzwingen + Selbst-Render-Probe (C8).** Two shared generation rules on all four engines: spread the RENDER/MATERIAL register (material-surface-light-weight feel), not just the domain; and a self-render-probe that grounds only the VAGUE Leitwerte (never flattening an already-concrete one — Leitwert ≠ render, E-024). The cheap judge now also classifies each card's render-register (one of eight), and `spreadByRegister` re-threads a cluster's floor-passers to span registers before the top-N slice — the #1 card keeps its rank, only the tail diversifies.|Domain-distance variety (DIVERSITY_RULE) still let a cluster collapse into one material feel — two far worlds both rendering as «verwittertes Vintage-Messing-Papier». Forcing register spread de-collapses the *visible* output; the render-probe pushes designValue at generation time, not only at the judge. Reuses the existing per-card judge call → zero new LLM round-trips.|
|E-066|**Progressive depth in the Board row (C10).** The lane Row already collapses to a lean teaser (Leitwert + sub-line + palette); on open it now shows only the GIST — taste-tag, mood, the one-line Herleitung, and the anchor/copy actions — with the rich dossier (worlds + rhyme · object · affordances) tucked behind a second «Tiefe zeigen» fold that resets when the row closes. Persona rows carry no dossier and show no toggle.|«Intern reich, außen schlank»: the full internal richness stays one click away instead of flooding the open row, so scanning many directions stays calm and the depth is there only when one direction earns the attention.|
|E-067|**Studio reworked into a bento FIELD; dead canvas deleted (D12 + entschlacken).** The four linear lanes (E-055) become a masonry of engine PANELS — each a HERO tile (its judge-#1) over smaller satellite tiles, so the strongest direction dominates instead of a flat list. Werkbank's satellites sub-cluster by taste-direction (D12 — orthogonal directions become labelled sub-groups, not a buried tag); every tile shows a render-register chip (E-065); clicking a tile opens a detail drawer carrying the progressive depth (E-066). The superseded hex canvas (`Constellation.tsx`, E-053) — unused since the Board (E-055), kept alive only by stale docs — is deleted, and its frosted `.flyout` styles are reused by the new drawer.|Four equal lanes read like spreadsheets — no hierarchy, no focal point, "sehr linear". A field with size-hierarchy + engine colour + taste sub-clusters fronts the strongest, most varied directions (the north-star) and finally gives D12 a home in the live UI. Deleting the dead canvas ends the docs-vs-code drift. (Dead canvas/gem CSS swept separately in E-068.)|
|E-069|**Export: a one-line trigger + target tabs (C9).** The export modal gains three target tabs — Midjourney (English image prompt + `--ar/--style`), ChatGPT (an art-director instruction), Brandboard (the layered style spec, default) — and above the full text a dense single line («eine Zeile, die trägt») that carries the whole vibe for paste-anywhere use. `buildTrigger` + `buildExportPrompt(c, target)` in `export.ts`.|One paste rarely fits every destination — a designer goes to Midjourney, to an assistant, or to a brand doc. Tabs format for each; the one-liner covers the case where a single line is enough. Both keep the Leitwert as the trigger and the layers as cues, never an essay.|
|E-077|**Tune the shared rules toward materiality; Latent worst cost/benefit (E-077).** The local eval (3 typical prompts × 5 engines, ~$0.83) showed the engines still drift into an abstract «Substantiv-Schlachtfeld» and reuse ruts (-Protokoll ×5, Fermentier ×4). So the shared `leitwert` rule now DEMANDS a tangible anchor (material/surface/form → Kopfkino) and bans pure system-compounds; `diversity` adds Fermentation/Miso to the MEIDE-list and hard-caps repeated suffixes. Verdict: **Engine E (Latent) is the worst cost/benefit** — two strong calls + embeddings for the same 5.0 peaks D/F hit in ONE call, plus the most duds; the Materialist's 2-call cost is justified (it delivers the target materiality), Latent's is not.|The prompts are the quality knob and now live in YAML, so tuning them is the cheapest lever. Latent's embedding premise renders neither faster nor better — the cut candidate.|
|E-076|**Cut generation spend ~4× (E-076).** The judge was billed once PER candidate (`judgeRank` → ~32 parallel calls/round, each re-sending the full JUDGE_SYSTEM); now ONE batched call scores the whole structure (`/api/judge` takes `items[]`, returns aligned `scores[]`) — system sent once, not N times (~5× fewer judge input tokens, verified live: 6 cards in one Haiku call). Plus `OVERSCAN` 8→6, `noveltyText` injection 50→20 Leitwerte, and a `maxOutputTokens` guardrail (8000 default, tight on the judge). Per round ~37 calls → ~8.|No infinite loop existed — the spend was real per-card judge fan-out + over-generation + uncapped output. «Nur Text» still costs tokens × model × calls; one structure in, all scores out kills the multiplier without touching quality.|
|E-074|**Centralize all prompt setup into YAML (E-074).** Every word-based Stellschraube — engine roles, processes, the five shared rule blocks (Leitwert · Diversität · Repertoire · Register · Render-Probe), negative examples, output specs, the judge rubric — moved out of hardcoded string-concatenation in `prompts.ts` into `api/_lib/setup/*.yaml` (one file per method, `_rules.yaml` for the shared blocks). `npm run setup` (also part of `build`) assembles them into `setup.generated.ts`; `prompts.ts` re-exports the same constant names, so the endpoints are untouched. Migration verified content-identical against a frozen snapshot; a test guards the assembly + rule-injection.|One tuning surface. The prompts ARE the product's quality knob; scattered as string concatenation, tuning them was slow and risky. In YAML at one place, we (and the user) can see and raise quality fast — the foundation for the Materialist variant and the multi-layer world-extraction.|
|E-071|**Deterministic objective eval + hardened harness (E-071).** A pure-function metric suite (`metrics.ts`: leitwertFormat · concreteness · antiCliche-vs-Anti-Korpus · distinctness/anti-mode-collapse) scores engine output with NO LLM judge → same input, same score. The `eval.ts` harness is timeout-bounded (never hangs), per-call retried, failure-recording (a stalled call never aborts the run), CLI-controllable (`--engines/--briefings/--n/--timeout/--retries/--out/--report`), and offline-reproducible via `--in <fixture>` (score a frozen sample, zero network). `setRequestTimeout` on the client makes a stalled engine fail fast instead of hanging the lane.|The LLM-judge eval was subjective, non-deterministic AND hung on a stalled gateway. An objective, reproducible scorecard — runnable offline on a frozen fixture — is the right fitness signal for comparing the methods and finding the weakest, and it cannot hang.|
