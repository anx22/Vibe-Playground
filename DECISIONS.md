|QS-2|**Pivot to the Denkanstoß-Cluster (no pre-designing).** Engines stop emitting finished design (palette/typography/designs/worlds) and emit an open cluster — `weltSatz` + `leitwert` + `metaphern`/`materialien`/`bildVergleiche` — that feeds a downstream design/image AI. Each engine mixes **nah/premium** (best-in-class from the brief's own world, conventions OK) and **fern/surprising** per round; `register` drives `spreadByMix` (felt, never labeled). Schema + `VibeCard` slimmed to the cluster; one reusable **`ClusterCard`** with discreet copy at three grains (einzeln/gruppiert/gesamt); the export modal is gone. Supersedes the design-output line (E-024, E-065, E-066, E-069 + the palette/register-chip parts of E-067).|The output was over-translating — finished hero/typo/grid proposals. The playground should hand raw, inspiring WORLD-MATERIAL and let the next AI design; and adapt premium↔far per brief. The prompts (now all YAML) are the quality knob.|
|E-079|**Two engines, prompts in YAML.** D+F merged into one **Synthese** (collision) engine; the app runs **Synthese + Persona**. Every LLM instruction lives in `api/_lib/setup/*.yaml` (`npm run setup` → `setup.generated.ts`).|D/E/F were the same far-world move; one + Persona is leaner and just as strong. YAML = one editable quality surface.|
|E-078|**Cut Engine E (Latent-Agent) and its embedding path.** Two strong calls + embeddings for the same peaks D/F hit in one call.|Worst cost/benefit; redundant with the collision move.|
|E-076|**Batched judge.** One `/api/judge` call scores the whole batch (`items[]` → aligned `scores[]`), system sent once, output capped. ~4× less spend.|Per-card judge fan-out was the real cost; one structure in, all scores out.|
|E-071|**Deterministic eval + hardened harness.** `metrics.ts` (pure-function scorecard) + `eval.ts` (timeout-bounded, retried, offline via `--in`).|A reproducible fitness signal that can't hang.|
|E-063/64|**Quality floor + novelty memory; thin stays thin.** The judge floor in `select.ts` keeps sub-bar cards off the board; a thin lane is not refilled. A persisted, capped novelty memory repels produced Leitwerte each round. An unscored card (judge outage) degrades to show-all, never an empty board.|Aligns selection with the north-star; an honest sparse board beats a best-of-bad refill.|
|E-052|**Open-proxy hardening.** `guard.ts` caps the public endpoints — clamp `n`, cap free-text length, block clients forcing premium/Opus on generation (premium stays only on the cheap judge). Session-unique card ids; CI (test + build + typecheck:api) + unit tests for the pure functions.|The open proxy was the one real cost/abuse risk; input caps remove the amplification without new infra.|
|E-029/30|**Vercel AI Gateway via a thin `api/` proxy; model tiers.** One server-side key; Studio = strong (Sonnet), judge = cheap (Haiku), Opus = eval only.|Zero markup, caching, fallbacks; bounds cost. Key never client-side.|
|E-014|**North star = speed to a credible, surprising (and premium-when-wanted) direction.**|Tempo leads; the human verdict is the quality ground truth.|
|E-001|**Leitwert is the core primitive** — a compressed, tangible world-reference; modifiers are additive.|The compound alone triggers a coherent visual world.|
